# Arindam Bhadra Books

Static companion-resource website for books by Arindam Bhadra.

## Current book

**Excel for Everyday Work**

Reader resources are served from `/excel/`. Keep this route permanent because it is intended to be printed in the book and encoded in its QR code.

## Deployment

Deploy the repository as a static site on Vercel. No build command or framework is required. The repository root is the site root.

## Downloads

Place the current reader files in `/downloads/` using these stable filenames:

- `Excel_for_Everyday_Work_Companion.xlsx`
- `Budget_Source.xlsx`
- `Power_Query_Practice_Files.zip`

The public page links to stable filenames so the files can be updated without changing the URL printed in the book.
